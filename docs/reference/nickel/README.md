# Nickel reference

Nickel's user manual and examples, copied unchanged from
[nickel-lang/nickel](https://github.com/nickel-lang/nickel) at commit
[`b5fb33d9`](https://github.com/nickel-lang/nickel/tree/b5fb33d9c274d38d59892bf789415436d86eeb70)
(`doc/manual` and `examples`), under its MIT license in [LICENSE](LICENSE).

They are here for reading while writing xD's Nickel files. They are not part
of xD: no build, test or format step reads this folder, and some examples
fail on purpose to show contract errors. To update, copy both folders again
from a newer commit and change the commit above.
